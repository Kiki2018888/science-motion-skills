# 用一段动作和一个画风制作动画

安装后，直接对 Agent 说「用爪哇皮影画一只螃蟹横着爬过石头，举起左钳」即可。也可以提供自己的剧本和分镜，或补一句「换成浮世绘，暂停在举钳那一帧做对比」。

个人安装目录是 `~/.agents/skills/019-pelican-era-film/`，其中应直接包含 `SKILL.md`。仓库内安装也可用 `.agents/skills/019-pelican-era-film/`。在 Codex 调用 `$019-pelican-era-film`。[安装与发现路径](references/codex-install.md)

生成新动画需要 Node.js 22+。从技能目录运行下面的命令可重做自带的纸船案例。

```sh
node scripts/style-scene.mjs list
node scripts/style-scene.mjs rules 浮世绘
node scripts/style-scene.mjs build --scene examples/paper-boat.js --style 浮世绘 --style 唐代白描 --out boat.html
```

双击 `boat.html` 即可离线播放。暂停后切换画风，两张画面的船都在同一位置。把 `--scene` 改为 Agent 为你写的新场景就能换故事。逐帧、导出与场景接口见[制作说明](references/scene-authoring.md)。

[机器人羽毛球在线展示](https://kiki2018888.github.io/science-motion-skills/)保留了最早手工细化的 20 场对照。需要复现鹈鹕原片时使用[原片操作手册](references/upstream-film.md)。[原作与许可](references/notices.md)
