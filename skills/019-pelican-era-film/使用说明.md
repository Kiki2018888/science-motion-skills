# 鹈鹕时代短片技能

这是给 Codex 用的技能目录，用来在**你自己选定的空目录**里取得固定版本的《鹈鹕测试》，按 20 种时代画法做复现、有限改动或明确的重写，并截一段短预览。

技能附带一个可离线运行的展示。下载 [机器人羽毛球 · 20 种画风](assets/showcase.html) 后双击打开，在「画风目录」中选一场，或用「全屏」连续播放。每种画风单独占据主画面，暂停后可以逐帧切换。击球声可用「声音」开启。

画材与风格源自 Elbert 的《鹈鹕测试》。本例改编了部分 MIT 画材代码与双骨骼运动学，并独立绘制两个机器人、五拍球局与展示界面。上游的许可与第三方声明随展示页一起保存。[原作仓库](https://github.com/orbitoo/pelican-test) · [固定版本](https://github.com/orbitoo/pelican-test/tree/59c8ca2657ce5b2cf067969b5bda19d6609af8ac) · [许可明细](references/notices.md)

未在 DeepSeek Harness 上安装或运行。

## 安装

个人技能的发现路径见 [安装说明](references/codex-install.md)。

```bash
mkdir -p "$HOME/.agents/skills"
cp -R skills/019-pelican-era-film "$HOME/.agents/skills/019-pelican-era-film"
```

只给某个仓库用时，复制到该仓库的 `.agents/skills/019-pelican-era-film/`。正确的标志是这个目录里直接有 `SKILL.md`。

在 Codex CLI 或 IDE 里用 `/skills` 或 `$019-pelican-era-film` 调用。列表里没有时，重开 Codex。

下面的复制命令不会由技能自动执行。需要你自己同意之后再运行。

## 取得影片

```bash
node "$HOME/.agents/skills/019-pelican-era-film/scripts/validate-skill.mjs"
"$HOME/.agents/skills/019-pelican-era-film/scripts/fetch-upstream.sh" "$HOME/work/pelican-test"
```

`<目标>` 必须是新目录或空目录。脚本发现里面已有文件会退出，不会清空。它检出的提交是 `59c8ca2657ce5b2cf067969b5bda19d6609af8ac`。不想下载约几十 MB 的 ttf 原件时，加上 `--skip-source-fonts`。woff2 仍会下载，字体许可义务不变。

这一步不运行 `pnpm install`。

## 预览和短截帧

```bash
node "$HOME/.agents/skills/019-pelican-era-film/scripts/preview-server.mjs" \
  --root "$HOME/work/pelican-test" --port 41731

node "$HOME/.agents/skills/019-pelican-era-film/scripts/capture-frames.mjs" \
  --project "$HOME/work/pelican-test" \
  --times 8,74 \
  --clip-start 73 --clip-seconds 4 --fps 8 \
  --out "$HOME/work/pelican-preview"
```

截帧需要本机已安装的 Chrome 或 Chromium，可用 `CHROME_BIN` 指定。短片没有声音。全片 60fps 导出不在默认步骤里。

## 怎么提需求

直接说想看哪一场，或想改哪一种材料。技能会先区分：

- 原样重放现有画面
- 改颜料、纸张、装裱或展签，主体不变
- 换角色或故事，这需要改对应场景的造型代码，不会自动波及另外 19 场

风格和文件路径在 `references/style-catalog.md`。
