# 聊天动效视频

使用本技能随附的本地 HTML/CSS/JS 模板和 Python 渲染器，生成 H.264 MP4。无需 API 或远程网页。模板来自用户确认的聊天组件 v03，保留 0.48 秒轻微泡泡膨胀与回稳、标点停顿和长对话自动上移。

## 输入与选择

将用户对话按原有顺序转换成 JSON，保留措辞和说话人。不要为压缩时长删改台词；单条长到超过一屏时按原有句界拆为同一说话人的连续消息，或在语义不清时询问。

参数映射：
- 横屏 / 16:9 → `aspect: landscape`，1920×1080；竖屏 / 9:16 / 抖音 / 视频号 → `portrait`，1080×1920。
- 微信 → `theme: wechat`；Claude → `claude`；ChatGPT → `chatgpt`；简洁卡片 → `minimal`。
- 逐字 / 打字机 → `mode: type`；整句跳出 / 气泡蹦出 / 泡泡弹出 → `pop`。
- 每条可用 `mode` 覆盖全局，支持普通消息弹出、重点句逐字展开。

优先沿用当前对话中用户已选参数。未指定时默认竖屏、微信、泡泡弹出，并简短说明；只有缺少实际对话内容等必要信息时才询问。左右关系按对话角色确定，并保持一致；通常提问者在右、回答者在左，三人以上用名字区分。不要凭姓名补充身份信息。

读 [references/config.md](references/config.md) 构造配置。用户未要求声音时输出无声视频；配音或 BGM 属于额外任务，不能擅自调用 MiniMax 或套用旧项目声音。若用户提供已测配音时间，用逐条 `start`、`hold` 和 `cps` 编排，确保完整文字读完再切换。

## 生成

在本项目中，配置、对话输入与输出统一写入 `output/001-chat-motion-render/` 的具体场景目录。技能文件作为只读模板，不把具体对话写入模板。

本机运行入口（`<skill>` 是本 SKILL.md 所在目录）：

```powershell
python -X utf8 '<skill>\scripts\render_chat.py' --config '<配置绝对路径>.json' --output '<输出绝对路径>.mp4'
```

脚本自动使用本机 Chrome 和项目既有 FFmpeg，不修改全局配置。其他环境可用含 `playwright`、`Pillow` 的 Python，并传 `--chrome`、`--ffmpeg`。`--fps` 支持 24 或 30，默认 24。无需安装 Playwright 自带浏览器。

输出已存在时选择新版本文件名，除非用户要求覆盖；`--overwrite` 仅覆盖指定输出及其对应源文件目录。不要为本次请求重新渲染所有风格。

## 检查与交付

脚本先校验输入、时间轴、换行、最终消息可见性及任意定位一致性，失败即停止，不交付失败产物。然后输出视频并核对尺寸、帧数和完整解码。过程帧经管道传输，不在 项目输出目录 中生成帧序列。

查看生成的 `<输出名>_source/contact.jpg`，确认样式、角色和文字布局；长对话也检查滚动后的末段。需要调整时修改配置后按新版本重跑。不要以字体缩小到不可读的方式强塞超长消息。

最终用绝对路径内嵌视频，并简短说明画幅、界面、出现方式及有无声音。源目录保留可预览 HTML、最终配置、字体许可和 `report.json`，方便后续修改。

竖屏重排给右侧与下方留白；这是设计预留，实际发布平台控件可能变化。界面为风格化重绘，不称为平台实际录屏。技能包含字体的 OFL 许可，复制模板时保留。

## Portable runtime

需要 Python 3.10+、Playwright、Pillow、Chrome/Chromium 与 FFmpeg/ffprobe。自动查找 PATH 和常见安装位置；也可传 `--chrome` / `--ffmpeg`，或设置 `CHROME_BIN` / `FFMPEG_BIN`。输出必须位于技能目录之外。


## 局部预览与统一编码

读 [共同渲染接口](references/rendering.md)。支持 `--frames START:END`、`--preview-frames` 和 `--profile bt709|legacy`；默认有限范围 BT.709，时间仍使用原场景时间轴。
