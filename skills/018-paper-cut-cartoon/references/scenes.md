# 镜头配置

根对象包含 `format`（`landscape` 1920×1080 或 `portrait` 1080×1920）、可选背景色 `background`、道具字典 `props` 和有序 `scenes`。CLI 的 `--format` 可覆盖配置。颜色使用六位十六进制。背景用暗纸最容易读出剪边和投影。

每镜的 `duration` 以秒计，对应 30 fps 整帧。`layers` 按从后到前绘制。`captions` 是可选的 `[[镜内起始秒,"文字"], …]`，空串收起胶带，可用换行指定断句。`transition` 默认 `cut`，设为 `peel` 时在本镜开头约 0.4 秒掀走上镜，转场占本镜时长。

| 图层 type | 内容与锚点 |
| --- | --- |
| robot | 铆钉机器人，以双脚中点为原点。原尺寸高约 455 像素。用 `color` 换机身色，`hand:[x,y]` 指定本地手部位置。 |
| person | 戴帽纸偶，以脚底为原点，原尺寸高约 175 像素。可改外套颜色，以 `walk:0…1` 调整步幅。 |
| prop | `prop` 引用 `props` 中的名称，路径坐标原点就是摆放点。 |
| label | `text` 为纸签文字，`color` 为纸色，`fontSize` 以像素计，`maxWidth` 为相对画布的可用文字宽度。 |
| swap | 纸手撕掉旧签，再拍上新签。填 `before`、`after`，可改旧纸色 `oldColor` 和新纸色 `color`。`impact` 为新纸贴上的镜内秒数，默认 1.55。 |

独立图层使用 `at:[x,y]`，两个值分别占画布宽与高的比例。原点在左上方。通用字段包括 `id`、`scale`、`angle`（度）、`facing:"left"`（镜像）、`start/end`（镜内秒）和 `enter:"drop"|"stamp"`。动作例子如下。把轨道名填进 `keys`，各属性在自身关键点间插值，最后一次取值持续到镜末，再按定格节奏取样。

```json
{"type":"robot","id":"guide","at":[0.35,0.74],"hand":[105,-144],
 "keys":[{"t":0.3,"handX":82},{"t":0.8,"handX":172,"handY":-210}],
 "portrait":{"at":[0.34,0.67],"scale":1.15}}
```

可动画化 `x,y,scale,angle,handX,handY,walk`。姿势参数是主动手端点相对于脚底的像素坐标。取物时先略后收，手先碰到道具，眼神或身体稍晚落到新位置。物体被握住的区间可以另建一道具图层，和桌面上的原图层用同一镜内时间交接。

绑定手部写 `"attach":{"to":"guide","point":"hand","offset":[12,28]}`；绑定任意已绘制图层的原点用 `"point":"origin"`。偏移跟随父图层的缩放、镜像与旋转，子图层的大小和角度仍可单独调整。挂点层用 offset 定位。父图层未入场时，所挂道具同时隐藏。

`props` 内每件道具是一组从后往前的 SVG 路径。一个元素的 `d` 描述轮廓，`fill` 选纸色，`edge/outline/shadow` 控制剪边颜色、宽度与硬影距离。`stroke/weight` 用于表面墨线或开放形状。示例如下。

```json
{"flag":[{"d":"M0 0 L0 -74 L82 -60 L0 -39 Z","fill":"#e64a3c"},
         {"d":"M0 0 L0 -76","stroke":"#f4efe6","weight":5}]}
```

竖屏版在各层的 `portrait` 中调整构图。它逐字段替换横屏值，替换 `keys` 时写完整的竖屏轨道。竖屏字幕条放在底部安全区上方，道具和纸偶的位置仍由镜头作者决定。用代表性关键帧检查角色入画、指向、碰触点与字幕的关系。
