# Provenance and scope

The initial eight UI style directions and dashboard prototype came from a user-provided Claude-generated document. Version 2 adds an independent freeform scene graph, keyframes, geometry changes, cubic paths, groups and examples. The legacy dashboard remains an optional compatibility mode.

Original implementation, configurations, procedural SVG illustrations and the preview are released under this repository's MIT license. The bundled unmodified Adobe Source font retains its SIL OFL 1.1 license in `assets/template/OFL.txt`. No third-party UI library or stock image is bundled.

The release uses shared renderer 2.0.0 and portable dependency discovery. The 50-second version 2 sample was approved on 2026-11-15. Verified configurations and platform scope are listed in the repository `VALIDATION.md`; arbitrary content combinations are not implied to have passed testing. The private source document and production records are not included.
